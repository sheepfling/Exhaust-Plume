# Deferred physical-optical tranche

The broader program still expects a future physical optical path after the API, plume-geometry, and mixing foundations are stable.

Planned identifiers retained for continuity:

- `RAY-001` — exact ray/volume geometry
- `RAD-001` — unit-safe thermal-radiation primitives
- `RAD-002` — segment transfer validation
- `RAD-003` — resolved transfer provider
- `SIG-002` — source-signature derivation from validated transfer
- `OPT-VAL-001` — optical validation/release gate

Detailed implementation issue bodies for this tranche are intentionally not published in this PR. They require a separate review before being turned into executable work. This does not alter the product-boundary decision that visual geometry, unresolved signature, and resolved optical transfer remain independent capabilities.
